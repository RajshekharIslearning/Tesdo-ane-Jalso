# Existing UI Inventory

## Navigation
- Desktop horizontal navigation bar (Navbar)
- Mobile hamburger menu and navigation drawer
- Footer links block (Legal, About, Contact)

## Layout & Containers
- Main page container (constrained width on desktop)
- Full-width hero sections
- Multi-column grid layouts for vendor lists
- Single-column stacked layouts for mobile

## Search & Filters
- Global search input (used for finding street food or vendors)
- Category/Filter dropdowns (Radix Select)
- Search results container

## Cards
- Vendor summary card (displays image, name, rating, locality)
- Ranking card (for community leaderboard)
- Review/Rating display block (stars + comment)

## Forms & Inputs
- Add Vendor form (multiple input fields, image upload zone)
- Report Issue form (textarea, dropdown reason)
- Contact form (Name, Email, Message, Submit)
- Admin Login form (Email/Password, Submit)

## Actions & Interactive Elements
- Primary CTA buttons (Add Vendor, Search, Submit)
- Secondary buttons (Cancel, Go Back)
- Radix UI Tabs (used on vendor details or admin pages to switch views)
- Radix UI Dialogs/Modals (used for confirmations or image previews)
- Toggle switches (Radix Switch)
- Toast notifications (Radix Toast)

## Loading & Empty States
- Radix UI Progress bars (for loading indicators)
- Empty state fallbacks (e.g., "No vendors found matching your search")
- 404 Not Found layout (for invalid vendor slugs)
